# Personal Portfolio Website

A personal portfolio website built to showcase my introduction, technical skills, projects, and development journey. This project represents my learning and practical experience in frontend web development.

## 🚀 Technologies Used

- **HTML5** – Structure and content of the website.
- **CSS3** – Styling, layouts, and visual design.
- **JavaScript** – Interactive elements and functionality.

## 📂 Project Structure

```text
Portfolio-Website/
│
├── html_files/       # HTML files
├── stylesheet/       # CSS stylesheets
├── script file/      # JavaScript files
├── images/           # Images and visual assets
│
└── README.md
```

## ✨ Project Overview

The portfolio is designed to provide an overview of my technical background and showcase my work as a developer.

It serves as a central place to present my skills, projects, and experience while applying my knowledge of frontend development.

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/harshit00052/Portfolio-Website-.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio-Website-
   ```

3. Open the main HTML file from the `html_files` folder in your browser.
